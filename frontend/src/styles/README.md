## Tamanhos de imagem (`images.css`)

| Variável | Valor | Uso |
|----------|-------|-----|
| `--img-produto-tamanho` | 160px | Cards de produto |
| `--img-categoria-tamanho` | 56px | Círculos de categoria |
| `--img-painel-largura` | 72px | Miniaturas carrinho |

Altere estes valores para redimensionar todas as imagens de uma vez.
